


# Tic Tac Toe AI in C++

A console-based Tic Tac Toe game built using C++ and Object-Oriented Programming.

## Features

- Human vs Human
- Human vs AI
- Unbeatable AI using Minimax
- Input validation
- Replay option
- Cross-platform

## Technologies

- C++17
- OOP
- Minimax Algorithm
- CMake

## Project Structure

include/
src/
screenshots/

## Build

g++ -std=c++17 -Iinclude src/*.cpp -o tictactoe

## Run

./tictactoe
